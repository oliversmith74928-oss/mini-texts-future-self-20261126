One funny text message from your future self, sent back to the present you.

`main.py` (Python standard library only) writes the message to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is
deterministic: the same bytes on every run.

## The text

> It's me, you, from 2041. The sourdough starter you keep forgetting has its own chair at dinner now. Feed it. Also stop buying plants — they unionized.

## Run

```sh
python3 main.py
```
